# Тестовый сценарий UART команд
# Порт: COM3, Скорость: 115200 бод
# Все команды отправляются с терминатором \r\n

# Шаг 1: Включить LED
AT+LED_ON

# Шаг 2: Проверить сырое значение ADC
AT+ADC_RAW?

# Шаг 3: Проверить процент освещённости
AT+ADC_PERCENT?

# Шаг 4: Сместить нижнюю границу вверх на 500
AT+CALIB_LOW+500

# Шаг 5: Проверить процент после калибровки
AT+ADC_PERCENT?

# Шаг 6: Ещё раз сместить нижнюю границу на 500
AT+CALIB_LOW+500

# Шаг 7: Проверить процент после второй калибровки
AT+ADC_PERCENT?

# Шаг 8: Проверить сырое значение ещё раз
AT+ADC_RAW?

# Шаг 9: Выключить LED
AT+LED_OFF
