# 📘 ДЛЯ НОВИЧКОВ — Настройка PlatformIO для STM32

## ❓ Что такое PlatformIO и где он находится?

**PlatformIO** — это система сборки для встраиваемых систем (как Arduino, но мощнее).

Когда вы устанавливаете расширение **PlatformIO IDE** в VS Code, оно устанавливается **отдельно** в папку:

```
C:\Users\ВАШЕ_ИМЯ\.platformio\
```

**Важно:** `.platformio` — это скрытая папка! Чтобы её увидеть, включите отображение скрытых файлов в проводнике.

---

## 🔎 Шаг 1: Найти путь к OpenOCD

OpenOCD — это программа для прошивки STM32 через ST-Link.

### Самый простой способ (рекомендуется):

1. Откройте **VS Code**
2. Нажмите **Ctrl+`** (откроется терминал)
3. Введите команду и нажмите Enter:

   ```bash
   python -c "import os; print(os.path.expanduser('~/.platformio/packages/tool-openocd/openocd/scripts'))"
   ```

4. Вы увидите что-то вроде:
   ```
   C:\Users\Alex Pronin\.platformio\packages\tool-openocd\openocd\scripts
   ```

5. **Скопируйте этот путь!**

### Альтернативный способ (через проводник):

1. Нажмите **Win+R** на клавиатуре
2. Введите: `%USERPROFILE%\.platformio\packages\`
3. Нажмите **Enter**
4. Найдите папку `tool-openocd`
5. Откройте её → `openocd` → `scripts`
6. В адресной строке проводника скопируйте путь

---

## ⚙️ Шаг 2: Настроить platformio.ini

1. Откройте файл `platformio.ini` в вашем проекте
2. Найдите строку:
   ```ini
   upload_command = openocd -s "C:/Users/..."
   ```
3. Замените путь на **ваш**, который вы скопировали:
   ```ini
   upload_command = openocd -s "C:/Users/ВАШЕ_ИМЯ/.platformio/packages/tool-openocd/openocd/scripts" -f interface/stlink.cfg -f target/$UPLOAD_FLAGS -c "init" -c "reset halt" -c "flash write_image erase .pio/build/debug/firmware.elf" -c "reset run" -c "shutdown"
   ```

**Пример:**
```ini
upload_command = openocd -s "C:/Users/Ivanov/.platformio/packages/tool-openocd/openocd/scripts" -f interface/stlink.cfg -f target/$UPLOAD_FLAGS -c "init" -c "reset halt" -c "flash write_image erase .pio/build/debug/firmware.elf" -c "reset run" -c "shutdown"
```

## 🚀 Шаг 3: Проверить работу

### Компиляция:

В терминале VS Code введите:

```bash
pio run -e debug
```

**Ожидаемый результат:**
```
Building .pio\build\debug\firmware.bin
========================= [SUCCESS]
```

### Прошивка:

```bash
pio run -e debug -t upload
```

**Ожидаемый результат:**
```
wrote XXXXX bytes from file .pio/build/debug/firmware.elf
========================= [SUCCESS]
```

## ❗ Частые проблемы

### Ошибка: "Can't find target/stm32f4x.cfg"

**Причина:** Неверный путь к OpenOCD в `platformio.ini`

**Решение:**
1. Проверьте, что путь существует (откройте его в проводнике)
2. Убедитесь, что в конце пути есть `/scripts`
3. Проверьте, что в папке есть файлы `interface/stlink.cfg` и `target/stm32f4x.cfg`

### Ошибка: "pio: command not found"

**Причина:** PlatformIO не установлен или не в PATH

**Решение:**
1. Откройте VS Code
2. Убедитесь, что установлено расширение **PlatformIO IDE**
3. Перезапустите VS Code
4. Попробуйте снова

### Ошибка: "No such file or directory: .pio/build/debug/firmware.elf"

**Причина:** Проект не скомпилирован

**Решение:**
```bash
pio run -e debug
```

## 📚 Полезные команды

| Команда | Описание |
|---------|----------|
| `pio run` | Скомпилировать проект |
| `pio run -t upload` | Прошить в MCU |
| `pio run -t clean` | Очистить сборку |
| `pio device list` | Показать подключённые устройства |
| `pio pkg list` | Показать установленные пакеты |

---

## 💡 Советы

1. **Всегда компилируйте перед прошивкой:**
   ```bash
   pio run -e debug -t upload
   ```
   Эта команда сначала скомпилирует, потом прошьёт.

2. **Используйте терминал VS Code** — все команды работают там.

3. **Сохраняйте файлы перед компиляцией** (Ctrl+S).

4. **Если что-то не работает** — попробуйте очистить сборку:
   ```bash
   pio run -t clean
   pio run
   ```
